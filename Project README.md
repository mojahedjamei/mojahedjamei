# Daneshkhaneh LMS 🏠📖

**A Complete Learning Management System built with WordPress**

Daneshkhaneh LMS is a professional E-Learning platform designed to manage educational courses, digital product sales, and student learning experiences. It provides a complete infrastructure for educational institutes to offer online training efficiently.

## 🎯 Project Objectives
* Introduce educational courses professionally.
* Create a robust online learning management system.
* Enable the sale of educational products and digital downloads.
* Manage users, students, and instructors effectively.
* Provide scalable architecture for future development.

## 🛠️ Technology Stack
* **WordPress:** Core Content Management System.
* **Tutor LMS:** Course architecture, lessons, and educational workflow management.
* **WooCommerce:** Store creation and digital product sales management.
* **Elementor:** Page design and User Interface creation.
* **Astra Theme:** Lightweight and optimized base theme.

## 🚀 Key Features
* **Course Management:** Complete structure for lessons, curriculum, and course introduction.
* **Instructor Dashboard:** Dedicated sections for instructors to manage their materials.
* **Student Portal:** Exclusive user dashboard for account management and course access.
* **Educational Store:** Integrated WooCommerce shop for purchasing courses.

## 📊 Performance Optimization Case Study
One of the most critical phases of this project was optimizing files and database structures for easier migration and deployment.
* **Initial Project Size:** ~ 1.8 GB
* **Final Optimized Size:** 176 MB
* **Outcome:** Faster loading times, easier server migration, and better resource management.
